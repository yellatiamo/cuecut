# Cuecut

Linux 优先的时间线视频剪辑原型。桌面端用 Electron，也可在浏览器里当本地 Web 应用运行。界面以中文为主，关键操作带英文。

名称、界面与文字样式均为原创，未使用第三方剪辑产品的商标或素材。

## 环境

需要 Linux、Node 20 以上。导出成片需要本机 PATH 中的 ffmpeg；没有 ffmpeg 时仍可预览。中文烧录建议安装 Noto CJK 字体。

## 如何运行

进入仓库根目录并安装依赖。
桌面窗口对应 package.json 中的 start 脚本（Vite 与 Electron）。浏览器模式对应 web 脚本，监听本机 5173 端口。

## 第一次打开

若还没有保存过项目，会自动生成演示片头、说明卡片和一条字幕。没有自己的素材也可以导出这段。项目自动写入 localStorage，顶栏可保存或打开 JSON。纯浏览器刷新后大视频可能需重新导入。

## 左侧分类

素材库左侧是功能分类轨，切换后只改左侧面板，预览、检查器与时间轴保持不动。

- **媒体 Media**：导入并拖入视频 / 音频 / 图片
- **音频 Audio**：列出音频、导入、从选中视频提取原声到 A1、静音原声、音量与淡入淡出、可选麦克风旁白；时间轴含 A1 / A2。预览用独立 HTMLAudio 与播放头同步
- **文字 Text**：灯牌 / 手记 / 字幕条 / 字幕 四种原创样式，在播放头插入标题
- **字幕 Captions**：列出全部文字片段（入出点可改文案）、在播放头添加约 3 秒字幕、导入 / 导出 SRT
- **转场 Transitions**：同一视频轨相邻片段可加交叉溶解或闪黑（存在片段上，预览用透明度）
- **导出 Export**：720p / 1080p、24 / 30 / 60 fps、草稿 / 标准 / 高质量（对应 ffmpeg CRF）、是否烧录字幕、文件名。顶栏「导出」会切到此分类

## 试用

**提取音频**：导入视频并拖到 V1，点选该片段 → 左侧「音频」→「提取音频到 A1」。勾选「提取时同时静音视频」则画面不再出原声。空格播放应能听到 A1。也可勾选检查器里的「静音原声」。

**SRT**：左侧「字幕」→ 导入 SRT，或点「添加字幕」后改文案。导出 SRT 会下载当前所有文字片段。

**导出预设**：顶栏「导出」打开左侧表单。选 720p + 草稿可较快出片；勾选「烧录字幕」会用 ffmpeg drawtext 画进 MP4。开始导出走现有 `/api/export`。

## 功能

- 素材库：导入本地视频、音频、图片，显示名称、时长、缩略图
- 预览：播放暂停、播放头、时间码；16:9 与 9:16；画面与时间轴同步，文字叠层；时间线音频真实发声
- 时间轴：两条视频轨、一条文字轨、两条音频轨（A1 / A2）；拖入、点选、移动、裁剪、分割、删除、缩放、scrub
- 检查器：音量、静音原声、透明度、位置、缩放、淡入淡出、转场；文字内容/字号/颜色/位置；四种原创样式
- 导出：若 PATH 上有 ffmpeg，则用 Node child_process 渲染 MP4 并显示进度；否则给出 Debian 系安装说明，预览不受影响
- 快捷键：空格播放，S 分割，Delete 删除，Ctrl+Z 与 Ctrl+Shift+Z 撤销重做

不包含账号、云素材、AI 与特效商店。
